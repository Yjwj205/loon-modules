# Loon 带宽测速

测你家宽带的速度，或单个节点的速度。默认用**腾讯 CDN 的 2GB 安装包**，按 Range 分块下载；**只测不改**，不会切换策略组。

## 安装

Loon → 插件 → 右上角 `+` → 从 URL 安装：

```text
https://raw.githubusercontent.com/Yjwj205/loon-modules/main/speedtest/NodeSpeedtest.plugin
```

要求 Loon **3.5.1 (983)** 及以上。

## 测速对象

插件里的「测速对象」决定测谁：

| 测速对象 | 走哪条线 | 测速地址 | 用途 |
|---|---|---|---|
| **自动**（默认） | 有入口节点就测节点，否则 `DIRECT` | Cloudflare `__down?bytes=N` | 点节点就测节点，在脚本页跑就测本地带宽 |
| 本地直连 | `DIRECT`，不走代理 | 同上 | 测自家宽带能跑多快 |
| 当前节点 | 策略组当前选中的节点 | 同上 | 测这个节点的速度 |
| 指定节点 | 入口节点 / 填写的节点名 | 同上 | 在节点详情运行时直接测它 |

测节点时，节点按「入口节点 → 节点名 → 策略组当前选中」的顺序取；都没有就报错提示。

## 结果示例

```text
测速
本地直连 · 312 Mbps
------------------
下载  312 Mbps（4 线程）
数据  10 MB / 0.26s
延迟  18 ms（抖动 3 ms）
耗时  1s
```

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 测速对象 | 自动 | 自动 / 本地直连 / 当前节点 / 指定节点 |
| 策略组 | 空 | 测节点时用；留空自动查找 |
| 节点名 | 空 | 指定节点时用；留空则用入口节点 |
| 下载大小(MB) | 300 | 1–1000；建议 ≥300 测准高带宽，脚本按 95 MB 分块续传 |
| 测速地址 | 空 | 留空用 Cloudflare（与 Surge 同源）；支持 `{bytes}`/`{size}`/`{mb}` |
| 备用测速地址 | 空 | 主源 429/403 时自动改用；留空自动（节点用 datapacket，本地用清华源） |
| 延迟测试地址 | 空 | 留空用 Cloudflare 0 字节（与测速同源） |
| 延迟采样次数 | 2 | 取最小值；`0` 表示不测延迟 |
| 并发连接数 | 4 | `1`=单线程；`2`-`8` 测多连接总带宽 |
| 超时(秒) | 240 | 下载单块的最长等待；低于 90 秒按 90 秒算 |
| 发送通知 | 开 | 关闭后只写脚本日志 |
| 启用 | 开 | 关闭后隐藏脚本入口 |

## 原理

- **本地直连**用 `$httpClient` 的 `node: "DIRECT"`，请求不经过代理；节点模式用 `node: "节点名"`，同样不需要切换策略组。
- **大流量分块**：`下载大小` 会被拆成每块 ≤95 MB 的多次请求，首尾相接（单线程时是串行续传），总速度仍按「总字节 ÷ 总耗时」算。腾讯源的 Range 偏移会依次前进，不会重复读同一段被 CDN 缓存放大。
- 腾讯 CDN 的固定地址会 302 到带签名的临时地址：脚本先解析出跳转地址，再用它对同一节点发 Range 请求。
- 固定大小的测速文件先发 `HEAD`，看服务器是否支持 `Range`：支持就按 `下载大小` 截取、并能多线程切片；文件比目标小时重复读取同一段 Range 凑够流量；不支持就整包下载、强制单线程（避免 N 倍流量）。
- 共享节点 IP 偶尔会被 Cloudflare 限流（429）：脚本会等 1.2 秒重试一次，仍失败则自动切到「备用测速地址」，结果里会标 `来源  备用源`。
- 带 `{bytes}` 占位符的地址由脚本自己控制每片大小，天然支持多线程。
- 下载前先发 256 KB 预热请求建立连接，尽量不把 TLS 握手算进成绩；请求都带 `Accept-Encoding: identity`。
- 速度 = 总字节数 × 8 ÷ 总耗时；多线程时按「总字节 ÷ 最长耗时」算总带宽。
- 请求统一带 `User-Agent: curl/8.5.0`：清华源等镜像会拦截浏览器/Loon 的 UA（直接 403），用 curl UA 放行。
- Loon 的回调只在响应结束时触发，拿不到中途进度，所以是整段平均速度，不是实时曲线。

## 推荐测速地址

| 适合 | 地址 | 说明 |
|---|---|---|
| 默认（本地 / 节点） | 腾讯 CDN 王者荣耀安装包（2GB） | 支持 Range，按 95MB 分块顺序读 |
| Cloudflare | `https://speed.cloudflare.com/__down?bytes={bytes}` | 与 Surge 内置测速同源；共享 IP 容易 429 |
| 国内镜像 | `https://mirrors.tuna.tsinghua.edu.cn/speedtest/100mb.bin` | 固定 100 MB，支持 Range；脚本已带 curl UA 绕过 WAF |
| 香港 | `https://hkg.download.datapacket.com/100mb.bin` | 固定 100 MB |
| 日本 | `https://tyo.download.datapacket.com/100mb.bin` | 固定 100 MB |
| 新加坡 | `https://sgp.download.datapacket.com/100mb.bin` | 固定 100 MB |
| 欧洲 | `https://proof.ovh.net/files/10Mb.dat` | 固定 10 MB |
| 英国 | `https://download.thinkbroadband.com/10MB.zip` | 固定 10 MB |

> 实测过返回 200 且能下完；cachefly、hetzner、leaseweb、vultr、tele2、linode 这些常见推荐目前不可用或已下线。

## 精度与流量

- 一次测速消耗 `下载大小 + 0.25 MB`（默认约 10.25 MB）；本地直连模式下这部分流量不经过代理。
- 「下载大小」可到 1000 MB；单请求上限 100 MB（Cloudflare 对 `bytes >= 100000000` 直接 403，实测 99,999,999 正常），所以按 95 MB 分块。
- 结果同时推通知和 Loon 脚本面板（`$done({title, message})`）。
- 想测满千兆/多百兆宽带，建议 20–50 MB + 4 线程；只看单连接质量就用 1 线程。
- 清华源对教育网最快，电信/联通家宽可能有跨网损耗；如果觉得偏低，把测速地址换成你所在运营商的大文件地址。
